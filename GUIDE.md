# Reader's Guide — awesome-python

## What this project is

**Awesome Python** is the curated catalogue of **Python frameworks, libraries
and tools** — the list you search when you need a Python package for a job and
want the community's proven options, organised so you can compare them in
minutes.

## How the content is organised

- [`README.md`](README.md) — the list (this guide was written from its
  section outline and the repository tree). Its flow:
  - **Categories** — a linked index grouping the catalogue into areas such as
    *AI & ML*, *Web Development*, *HTTP & Scraping*, and more.
  - **Projects** — the catalogue itself: 77 sub-category sections including
    AI and Agents, Deep Learning, Machine Learning, Natural Language
    Processing, Computer Vision, Web Frameworks, Web APIs, Authentication,
    CMS, ORM, Database, Caching, Data Analysis, Data Visualization, Testing,
    Debugging Tools, DevOps Tools, Task Queues, Messaging, CLI Development,
    GUI Development, Image Processing, Game Development and Functional
    Programming.
  - **Resources** and **Contributing** — further reading and the submission
    rules (see also `CONTRIBUTING.md`).
- `docs/` and `website/` — the material and build for the project's website
  edition of the list.
- `DESIGN.md` — the design notes for that presentation; `SPONSORSHIP.md` —
  sponsorship information; `CODE_OF_CONDUCT.md` — community rules.

## How to use it

1. Open the README's **Categories** index and jump to your area.
2. Scan that section's entries — each is a project link with a one-line
   description — and shortlist candidates.
3. Adding a project? `CONTRIBUTING.md` defines the bar and the format.
